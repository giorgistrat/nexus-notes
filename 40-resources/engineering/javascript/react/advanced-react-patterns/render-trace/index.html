Advanced React Patterns — Line-by-Line Render Trace

Index for a companion set of notes to Advanced React Patterns. Where the notes linked from that MOC explain concepts (what problem a pattern solves, what the API looks like), these notes trace execution order through the actual solution code of each exercise of EpicWeb’s Advanced React Patterns workshop by Kent C. Dodds — what renders first, when state/context/refs get read or written, what re-renders and why, and why each pattern needed the specific React primitive it used.

One note per exercise, each covering every step’s solution code in order, with real code pulled from the workshop repo (~/epic-workshops/advanced-react-patterns) and a step-numbered render trace. Read them in order — later exercises build on patterns established in earlier ones (compound components build on composition; slots and prop getters both extend compound components; state reducer and control props both build on state initializers).

Notes, in order

  1. 01 Composition — building elements where the data lives instead of drilling props through layout components. Step compose.
  2. 02 Latest Ref — using a ref (not state) to give a stable callback identity access to the latest render’s values without becoming a useEffect/useCallback dependency. Step ref.
  3. 03 Compound Components — sharing implicit state between a component and its children via React.Children/cloneElement, then via context, plus runtime prop-type validation. Steps context, validation.
  4. 04 Slots — a context-based alternative to compound components for deeply nested or reorderable children, plus a generic hook version and a render-prop/children-as-function variant. Steps context, generic, prop.
  5. 05 Prop Getters — a reusable-state-logic hook (state collection) and the prop-getter functions that fix the callback-collision problem consumers hit when composing their own handlers with the hook’s. Steps collections, getters.
  6. 06 State Initializers — accepting an initial* prop so a custom hook’s consumer can set the starting state, and keeping that initial value stable across re-renders with a ref/lazy initializer. Steps initial, stability.
  7. 07 State Reducer — inverting control so the consumer of a hook can intercept and override every state transition via a reducer they supply, plus a default-action-types escape hatch. Steps reducer, default.
  8. 08 Control Props — fully controlled/uncontrolled dual-mode components, warnings for mixing the two incorrectly, and the onChange contract that makes controlling a hook’s state possible. Step control.
